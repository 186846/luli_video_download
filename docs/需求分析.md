# 速下 SpeedyDL — 需求分析文档

> 文档用途：沉淀业务背景、范围与验收标准，供后续迭代及 AI 辅助开发时作为上下文输入。  
> 关联文档：[方案设计](./方案设计.md) · [接口文档](./API.md) · [部署文档](./部署文档.md)

## 1. 背景与目标

### 1.1 背景

许多平台不提供便捷下载，或不支持批量、高清、跨端保存。同学希望有一个**学习向**的万能视频下载站点，能粘贴链接后解析并保存到本地（含手机浏览器）。

项目更强调**学习新开发模式**（前后端分离、薄封装开源能力、转化型落地页），而非商业盗版工具。使用须尊重版权，注意平台封号风险。

### 1.2 产品目标

| 目标 | 说明 |
|------|------|
| 核心价值 | 粘贴 URL → 解析信息 → 选格式 → 下载到本地 |
| 体验 | 页面简洁、转化感强、移动端可用 |
| 技术 | Python 后端薄封装 yt-dlp；Vue 前端独立工程 |
| 合规姿态 | 页脚与文案强调个人学习、尊重版权 |

### 1.3 品牌与参考 UI

- 品牌名：**速下 / SpeedyDL**
- 主色：`#1777FF`（对齐参考站）
- UI 参考：[鱼皮 AI 导航 · AI 绘图提示词](https://ai.codefather.cn/painting)
  - 白底 + 浅蓝氛围、半透明顶栏
  - Hero：大标题关键词高亮 + 胶囊输入 + 实心蓝按钮
  - 卡片网格、轻阴影、圆角约 12px
  - 详情式左右栏（左预览、右操作）+ VIP 转化门禁

## 2. 用户与场景

### 2.1 目标用户

- 学习全栈 / 学习 yt-dlp 封装的同学
- 需要把**公开可访问**视频保存到本地做学习笔记的个人用户

### 2.2 核心场景（阶段 3 必须跑通）

1. 用户打开站点，粘贴视频页 URL，点击「解析」
2. 展示封面、标题、时长、平台、清晰度列表
3. 选择清晰度（免费档默认 ≤720p）
4. 点击「下载到本地」→ 显示进度 → 浏览器保存文件
5. 可换链接重新解析；手机同网可访问前端完成上述流程

### 2.3 扩展场景（阶段 4+，非阶段 3 阻塞）

- 演示会员解锁更高清晰度
- 直链复制、字幕下载、本地历史记录
- 视频总结 / 字幕翻译（预留）

## 3. 功能需求分层

### 3.1 阶段划分（与研发节奏对齐）

| 阶段 | 内容 | 阶段 3 状态 |
|------|------|-------------|
| 阶段 1 | FastAPI + yt-dlp：解析 / 服务端下载 /（后补直链） | 已完成基础 |
| 阶段 2 | Vue3 + Vite 前端骨架（样式按参考站一步到位，非先糙后美） | 已完成 |
| **阶段 3** | **联调：解析 → 信息展示 → 选格式 → 下载全流程** | **本阶段交付** |
| 阶段 4 | UI 精雕强化 + VIP 引导区 + 平台展示强化 | 已基本具备，可继续打磨 |
| 阶段 5 | 字幕、进度增强、历史、移动端优化等 | 已部分具备 |

### 3.2 阶段 3 功能清单（验收用）

| 编号 | 需求 | 优先级 |
|------|------|--------|
| R3-1 | 粘贴合法 URL 可成功解析并展示元数据 | P0 |
| R3-2 | 清晰度列表可选；默认选中可用免费档 | P0 |
| R3-3 | 服务端下载任务 + 进度轮询 + 文件下载 | P0 |
| R3-4 | 封面可显示（含防盗链代理） | P0 |
| R3-5 | 错误时有可读提示（无效链接、解析失败等） | P0 |
| R3-6 | 前端视觉对齐参考站（Hero / 结果双栏 / 主色） | P0 |
| R3-7 | 版权声明可见 | P1 |

### 3.3 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 解析超时由网络与平台决定；下载进度可见 |
| 并发 | 服务端同时下载任务数有上限（默认 2） |
| 存储 | 无数据库；临时文件 TTL 清理（默认约 15 分钟） |
| 安全 | 封面代理禁止内网地址；学习演示 VIP 非真实支付 |
| 兼容 | 现代桌面浏览器 + 手机浏览器（同网访问） |

## 4. 约束与边界

### 4.1 必须遵守

- 不修改 yt-dlp 上游源码，以官方 Python API / CLI 能力为准
- 不接真实支付 / 用户账号体系（第一期）
- 不鼓励下载未授权内容；产品文案需提示风险

### 4.2 明确不做（阶段 3）

- 播放列表批量下载的完整产品化
- 真实会员支付、账号登录
- AI 视频总结 / 机翻字幕能力落地
- 公网抗封禁、大规模多租户部署

### 4.3 下载模式决策

| 模式 | 说明 | 阶段 3 |
|------|------|--------|
| ① 服务端下载后给文件 | 体验稳，支持音视频合并 | **主路径（必须跑通）** |
| ② 直链重定向/复制 | 不占空间，合并清晰度常不可用 | 可并存，非阶段 3 阻塞 |

## 5. 验收标准（阶段 3）

1. 后端 `uvicorn`、前端 `npm run dev` 可同时启动  
2. 打开前端首页，UI 具备参考站风格信号（蓝主色 Hero、胶囊输入、结果卡片）  
3. 使用公开可访问测试视频完成：**解析 → 选格式 → 下载到本地文件大小 > 0**  
4. 非法 URL / 解析失败有错误提示  
5. 接口说明见 [API.md](./API.md)；架构见 [方案设计.md](./方案设计.md)

### 已验证记录（开发自测）

- 样例 MP4 直链：解析成功 → 下载完成 → 文件约 10MB  
- 前端开发地址：`http://127.0.0.1:5173`  
- 后端地址：`http://127.0.0.1:8000`

## 6. 术语表

| 术语 | 含义 |
|------|------|
| 解析 | `extract_info(download=False)`，取元数据与 formats |
| format_id | yt-dlp 格式选择串，可含 `+` 表示合并 |
| 演示会员 | localStorage + `vip_token=demo-vip`，非真实付费 |
| 封面代理 | 后端拉取封面并回传，规避 CDN 防盗链 |
