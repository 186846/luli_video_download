## 1. 结论

**阶段 3 核心能力已完成并可演示：**

粘贴链接 → 解析元数据/清晰度 → 选择格式 → 服务端下载 → 浏览器取文件。

附带能力：直链复制、字幕下载（有源时）、AI 视频总结（字幕优先 / Mock）、封面代理、演示 VIP 清晰度门禁、本地解析历史、抖音无 Cookie 解析下载。

## 2. 做了什么

| 模块 | 内容 |
|------|------|
| 后端 | FastAPI + yt-dlp 薄封装；内存任务表；临时文件 TTL 清理 |
| 前端 | Vue 3 + Vite 单页；参考站风格结果卡（封面/清晰度网格/立即下载） |
| 抖音 | 不依赖用户 Cookie：分享页 `_ROUTER_DATA` + `aweme` 播放接口 |
| 其它平台 | 走 yt-dlp（B 站等已验证；部分站需网络/Cookie 视平台而定） |
| 文档 | 需求、方案、API、部署、本文总结 |

### 2.1 主路径（模式①）

```text
浏览器 ──POST /api/parse──► FastAPI ──► yt-dlp 或 douyin.py
       ◄── 标题/封面/formats ──

浏览器 ──POST /api/download──► 创建 task ──► 后台线程下载到 downloads/tmp/
       ──GET /api/tasks/{id}──► 轮询进度
       ──GET /api/files/{id}──► 触发保存
```

### 2.2 关键设计决策

- **不 fork yt-dlp**，只调用官方 Python API。
- **无数据库**：任务与进度在内存；进程重启即丢；适合学习演示。
- **免费档 ≤720p**；更高清晰度需演示 VIP（`vip_token=demo-vip` / localStorage），非真实支付。
- **封面经 `/api/thumbnail` 代理**，避免浏览器本地 Referer 导致 CDN 403。
- **抖音单独分流**：yt-dlp 对抖音常要求 Cookie；`app/douyin.py` 用公开分享页方案，用户无需导出 Cookie。

## 7. 已知限制

1. **平台风控**：抖音页面结构变更、私密/删除稿、海外 IP 等可能导致解析失败。  
2. **yt-dlp 站点差异**：YouTube 等可能因网络或登录策略失败，与本项目封装无关。  
3. **任务不持久**：多 worker / 重启会丢进度；生产须保持 `uvicorn --workers 1`。  
4. **演示 VIP**：非真实会员体系。  
5. **合规**：勿用于未授权传播；公网大规模对外提供下载服务风险高。  
6. **AI 总结**：依赖平台字幕 / 弹幕 / 元数据；无可用文本且配置了真实 Key 时会报错。
