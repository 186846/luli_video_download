# 腾讯云轻量 + 宝塔面板部署

速下 SpeedyDL：Vue 3 前端 + FastAPI 后端 + SQLite。  
适用：**腾讯云轻量应用服务器 + Linux 宝塔**。

本地开发见 [部署文档.md](./部署文档.md)。

---

## 0. 架构（先看懂再动手）

```text
浏览器 → 宝塔 Nginx :80/:443
            ├─ /              → /www/wwwroot/luli/web/dist   （前端静态）
            ├─ /api/          → 127.0.0.1:8000              （业务 API）
            └─ /docs /redoc   → 127.0.0.1:8000              （可选：Swagger，仅调试）
```

| 对 | 错 |
|----|----|
| 前端走 Nginx 80/443 | 外网访问 `:5173`（开发端口，云上没有） |
| API 经 Nginx `/api` | 外网直连 `:8000` / `:8001` |
| uvicorn 绑 `127.0.0.1:8000` | 对公网开放 8000 |
| `--workers 1` | 多 worker（任务在内存会乱） |

推荐项目目录：`/www/wwwroot/luli`。

---

## 1. 轻量控制台

1. 购买轻量（建议 ≥ 2 核 4G），系统可用 OpenCloudOS / Ubuntu。
2. **防火墙**放行：`22`、`80`、`443`、宝塔端口（如 `8888`，建议仅自己 IP）。
3. 记下公网 IP。有域名则加 A 记录；大陆机房需 ICP 备案。

---

## 2. 宝塔准备

1. 安装宝塔（应用镜像或官网一键脚本）。
2. 装 **Nginx**（LNMP 即可；本项目不用 MySQL/PHP）。
3. 软件商店建议装：**Supervisor 管理器**、**Node.js 18+**（若在服务器上 build 前端）。
4. 安装依赖：

```bash
# OpenCloudOS / CentOS 系
dnf install -y python3 python3-pip python3-devel ffmpeg
# Ubuntu 系则用：apt install -y python3 python3-pip python3-venv ffmpeg

python3 --version    # 要 3.11+；没有 python 命令是正常的，用 python3
ffmpeg -version
```

## 4. 后端环境

```bash
cd /www/wwwroot/luli
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt -i https://mirrors.cloud.tencent.com/pypi/simple
mkdir -p data downloads/tmp
cp .env.example .env
chmod 600 .env
```

### 4.1 编辑 `.env`（线上必改）

```env
# ★ 必须是网站对外地址，不要带 :5173 / :8001
SPEEDYDL_PUBLIC_BASE_URL=http://你的公网IP
SPEEDYDL_API_PUBLIC_BASE_URL=http://你的公网IP

# 有域名且已 HTTPS 时改为：
# SPEEDYDL_PUBLIC_BASE_URL=https://你的域名.com
# SPEEDYDL_API_PUBLIC_BASE_URL=https://你的域名.com

SPEEDYDL_ALLOW_DEMO_VIP=0

# 可选 AI
# SPEEDYDL_AI_API_KEY=
# SPEEDYDL_AI_BASE_URL=https://api.deepseek.com/v1
# SPEEDYDL_AI_MODEL=deepseek-chat

# 可选 Stripe
# SPEEDYDL_STRIPE_SECRET_KEY=sk_test_或_sk_live_...
# SPEEDYDL_STRIPE_WEBHOOK_SECRET=whsec_...
```

> Stripe 支付成功回跳用 `SPEEDYDL_PUBLIC_BASE_URL`。写成 `:5173` 会跳到打不开的页面。

### 4.2 启动后端

**方式一：nohup（先跑通）**

```bash
cd /www/wwwroot/luli
source .venv/bin/activate
nohup uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1 > app.log 2>&1 &

curl -s http://127.0.0.1:8000/api/health
# 应含 "ok": true
```

**重启：**

```bash
pkill -f 'uvicorn app.main:app'
cd /www/wwwroot/luli && source .venv/bin/activate
nohup uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1 > app.log 2>&1 &
```

**方式二：Supervisor（推荐长期用）**

| 项 | 值 |
|----|-----|
| 名称 | speedydl |
| 启动目录 | `/www/wwwroot/luli` |
| 进程数 | **1** |
| 启动命令 | `/www/wwwroot/luli/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1` |

```bash
chown -R www:www /www/wwwroot/luli/data /www/wwwroot/luli/downloads
```

改 `.env` 后必须重启后端进程。

## 5. 前端

### 5.1 构建（二选一）

**服务器上构建：**

```bash
cd /www/wwwroot/luli/web
npm install && npm run build
```

**或本机构建**后上传 `web/dist/` 覆盖服务器同名目录。

产物路径：`/www/wwwroot/luli/web/dist`。

> `web/vite.config.js` **不用改**（只影响本地 `npm run dev`）。

### 5.2 宝塔添加网站

1. 网站 → 添加站点 → 域名填公网 IP 或域名。
2. **根目录**：`/www/wwwroot/luli/web/dist`（不要指到仓库根目录）。
3. PHP：纯静态；不必建数据库。

### 5.3 Nginx（改站点配置，不是全局 nginx.conf）

路径：该站点 → **设置** → **配置文件**（不要改「软件商店 → Nginx → 配置文件」主配置）。

关键片段：

```nginx
root /www/wwwroot/luli/web/dist;
index index.html;

location / {
    try_files $uri $uri/ /index.html;
}

location /api/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;

    client_max_body_size 20m;
    proxy_read_timeout 600s;   # AI 总结 SSE
    proxy_send_timeout 600s;
    proxy_buffering off;
}

# —— 可选：外网打开 FastAPI 接口文档（仅调试；正式环境建议删掉）——
# FastAPI 接口文档（Swagger UI）
location /docs {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
}

# Swagger / ReDoc 依赖的 OpenAPI JSON
location /openapi.json {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
}

# FastAPI 接口文档（ReDoc）
location /redoc {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
}
```

也可用面板「伪静态」+「反向代理」生成，再补上超时与 `proxy_buffering off`。

### 5.4 验收地址

| 用途 | 地址 |
|------|------|
| 首页 | `http://公网IP/` |
| 健康检查 | `http://公网IP/api/health` |
| 接口文档 Swagger | `http://公网IP/docs`（需已加上面三段反代） |
| 接口文档 ReDoc | `http://公网IP/redoc` |
| 服务器本机文档 | `http://127.0.0.1:8000/docs`（不经 Nginx） |

未配置 `/docs` 反代时，外网打开会 404；业务接口仍走 `/api/...`。

## 6. 数据库

SQLite，文件：`/www/wwwroot/luli/data/speedydl.db`（首次启动自动创建）。

- 无需安装 MySQL。
- 保证运行用户对 `data/`、`downloads/` 可写。
- 备份：复制 `data/speedydl.db`。

## 7. Stripe（可选）

1. `.env` 填写 Secret Key、Webhook Secret。
2. Stripe Dashboard → Webhooks 端点：

```text
http://公网IP/api/billing/webhook
# 有 HTTPS 域名后改为：
# https://你的域名.com/api/billing/webhook
```

事件：`checkout.session.completed`、`checkout.session.async_payment_succeeded`。

3. `SPEEDYDL_PUBLIC_BASE_URL` 必须是用户浏览器能打开的地址（**无 :5173**）。
4. 生产收款建议 HTTPS + Live 密钥。

支付成功应跳到：`http://公网IP/?billing=success&session_id=...`

---

## 8. 域名与 HTTPS（建议）

1. 域名 A 记录 → 公网 IP；防火墙已放行 80/443。
2. 宝塔站点 → SSL → Let’s Encrypt → 强制 HTTPS。
3. `.env` 两个 BASE_URL 改为 `https://你的域名.com`，**重启后端**。
4. Stripe Webhook、回跳一并改成 https 域名。

```bash
cd /www/wwwroot/luli
# git pull   或重新上传文件
source .venv/bin/activate
pip install -r requirements.txt    # 有依赖变更时
```

## 10. 排障

| 现象 | 处理 |
|------|------|
| `python: command not found` | 用 `python3` |
| 502 | `curl 127.0.0.1:8000/api/health`；看 `app.log` / Supervisor |
| 首页开了、接口挂 | 根目录是否 `web/dist`；`/api` 反代是否在**站点**配置里 |
| 外网 `/docs` 404 | 站点配置是否加了 `/docs`、`/openapi.json`、`/redoc` 反代 |
| 支付成功跳 `:5173` 拒绝连接 | `.env` 的 `PUBLIC_BASE_URL` 去掉端口，重启后端 |
| 付了不是 VIP | 检查 Webhook URL、`WEBHOOK_SECRET`、Nginx 是否转发 `/api` |
| SSE 卡住 | `/api` 关 `proxy_buffering`，超时 600s |
| ffmpeg 报错 | `dnf/apt install ffmpeg` |
| Cookie / 登录异常 | 全程同一域名（或同一 IP），勿混用带端口的开发地址 |
